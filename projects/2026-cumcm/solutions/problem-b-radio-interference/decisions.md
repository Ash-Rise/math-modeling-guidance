# 关键模型决策

## B-D01 / 以可行集合表达测角误差

- **Status：** Accepted
- **Decision：** 每次示向观测形成半角 1° 的闭楔形约束，多次观测通过集合求交更新源位置。模型保留有界误差语义，并以解析直线、圆弧和圆盘边界计算定位区域。
- **Reason：** 示向误差给出方向区间而非单一点估计，可行集合能直接保留最坏情形保证。
- **Supersedes：** None
- **Implications：** 问题一的定位区域、后续观测更新和几何实现均使用同一闭集合语义。

## B-D02 / 将可靠清除写成包围圆证书

- **Status：** Accepted
- **Decision：** 定位区域直径用于描述尺度；可靠清除由最小包围圆半径不超过 20 m 认证。
- **Reason：** 区域直径不能单独保证存在一个清除点覆盖全部可能位置，最小包围圆直接对应清除半径要求。
- **Supersedes：** None
- **Implications：** 该证书进入几何实现、第二观测点评价、结果证据和论文结论。

## B-D03 / 第二观测点同时评价信息与行动代价

- **Status：** Accepted
- **Decision：** 候选位置首先满足再次接收保证，再比较最坏响应区域和移动时间；论文分别报告两类指标。
- **Reason：** 定位区域收缩衡量信息增益，移动时间衡量执行成本，两者含义不同且都会影响任务质量。
- **Supersedes：** None
- **Implications：** 第二观测点搜索保留可行性门槛，并分别输出几何与行动指标。

## B-D04 / 全局策略采用确定性覆盖构造

- **Status：** Accepted
- **Decision：** 问题三使用七点全向覆盖，问题四使用 69 点定向发现覆盖，并在发现后进入局部示向与清除。
- **Reason：** 确定性覆盖直接提供全区域发现保证，并能与发现后的局部定位和清除流程衔接。
- **Supersedes：** None
- **Implications：** 离线任务、覆盖图、运行成本与论文 Q3—Q4 策略均以该构造为准。

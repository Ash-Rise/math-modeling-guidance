# 关键模型决策

## C-D01 / 统一储能与时间口径

- **Status：** Accepted
- **Decision：** 充电效率和放电效率均取 0.9；电价、负载和光伏的同一列共同对应前一个 10 分钟供电区间。功率乘 $1/6$ 小时转为区间电量。
- **Reason：** 统一时间索引、功率与电量口径，使供需平衡、库存递推和费用计算使用同一物理含义。
- **Supersedes：** None
- **Implications：** 四问的储能约束、费用汇总、结果表和论文表述均沿用该口径。

## C-D02 / 问题二采用因果预测与经济分位

- **Status：** Accepted
- **Decision：** 周同点基础预测叠加 28 天半衰期的日均偏差自回归修正，再按历史同点残差的 0.782 分位形成供给目标。分位由一月闭环费用校准，二月至十二月保持结构与参数固定。
- **Reason：** 预测仅使用决策时点已有历史，经济分位在计划购电与紧急购电代价之间形成可解释的风险权衡。
- **Supersedes：** None
- **Implications：** 问题二的年度运行、问题四对应分支及论文费用比较使用同一预测结构和风险水平。

## C-D03 / 问题三保留逐次订单状态

- **Status：** Accepted
- **Decision：** 0、6、12、18 时发布预报后滚动修订未来订单；每次调整以上一版有效订单为基准，履约、增购和取消分别计价。四个发布时间共用 0.70 的经济风险分位。
- **Reason：** 日内多次预报改变的是同一组未履约订单，保留订单状态才能正确表达调整量及对应成本。
- **Supersedes：** None
- **Implications：** 问题三和问题四对应分支按同一订单递推、交易权限和计费口径实现。

## C-D04 / 问题四区分预测价与结算价

- **Status：** Accepted
- **Decision：** 未来规划使用三周同点历史均值预测价格；当前执行和最终费用采用对应时段实际价格。问题四的两条分支分别继承问题二、三的预测、风险水平与交易权限。
- **Reason：** 该信息边界避免规划使用未来实际价格，同时使费用仍按题目给定的真实时段价格结算。
- **Supersedes：** None
- **Implications：** 价格预测接口、滚动调度、费用分解和论文结论必须区分规划价与结算价。

# 工作流入门

本仓库的项目采用完整工作流，让题意、决策、实现、结果和论文分别拥有稳定入口。

Git 是推荐的基础运行方式：它记录模型、代码、结果和论文的演进，也为比较、回退与恢复提供统一入口。当前项目事实由各类权威文件承载，Git 负责保存这些文件如何演进。

## 项目结构

```text
project/
├─ problem-statement.md    # 任务概要与关键条件
├─ decisions.md            # 已接受的重大语义决定
├─ state.md                # 当前执行前沿与下一步
├─ src/                    # 模型与实现
├─ scripts/                # 求解、复算、绘图和交付入口
├─ results/                # 论文引用的正式结果
├─ tests/                  # 模型合同与回归检查
└─ paper/
   ├─ figures/             # 正文图表
   ├─ paper.md             # 论文内容
   ├─ paper.docx           # Word 成稿
   └─ paper.pdf            # PDF 成稿
```

`state.md` 服务持续推进与跨会话恢复，项目进入稳定交付后可压缩为简短的当前状态。`decisions.md` 聚焦已经接受且会影响模型含义的决定。

[从决策到论文主张](decision-to-claim-case-study.md) 用一个关键决策展示模型含义如何进入实现与论文。

## 执行顺序

1. 从原题和附件提取任务、数据、单位、硬约束、评价方式与交付要求，形成稳定的机器阅读入口。
2. 查阅已有关键决策，区分题目事实、模型语义和普通技术选择；能够由权威材料消歧的事项直接继续。
3. AI 调查可行模型、数据条件和证据需求，自主处理普通实现与数值技术选择。
4. 当仍有多个合理选择，且选择会实质改变题意解释、模型含义、重要假设、目标、硬约束、评价口径、实质范围或结论解释时，形成决策提案并由人类决定。
5. 将接受的关键决定写入 `decisions.md`，随后完成模型、代码、实验和影响范围内的验证；稳定且可机械检查的语义可以转化为测试合同。
6. 将论文采用的数值、图表和核验结果固定到正式结果入口，使每项主要主张都能追溯到推理与证据。
7. 论文按“主张—推理—证据—边界”组织，并同步 Markdown、Word 与 PDF。
8. 在阶段边界更新 `state.md`，交付时核对模型、结果、图表、正文和版式的一致性，并清理已完成使命的临时文件。

每个阶段完成后提交一组含义清晰的 Git 变更，使关键决策、实现、结果和论文保持在同一项目版本。Git 保存历史，当前模型含义由原题、关键决策和正式结果共同确定。

普通工作沿稳定分支持续推进。对于影响多个下游产物、集成风险较高或需要查看完整候选状态的变更，使用一个临时分支集中承载；在该分支完成影响范围内的验证和差异审阅后，再合并回稳定分支。分支负责隔离候选实现，关键模型语义仍由原题和 `decisions.md` 确定。

## 人机分工

AI 负责持续推进：整理输入、调查方案、建立模型、编写代码、运行计算、制作图表、检查失败模式、维护状态和同步论文。普通技术选择无需等待人类确认；影响数值质量、复现性或效率的重要技术选择可以先执行，并在阶段报告中说明。

人类只负责关键决策：选择会改变问题解释、模型语义、重要假设、目标与硬约束、评价指标、允许资源、实质范围或最终结论含义的方案。AI 在提问前先完成权威核对和必要分析，给出真实可行的选择、推荐理由及主要代价；其他事项继续自主推进。

`decisions.md` 保存已经接受的关键决定，`state.md` 保存需要跨会话延续的执行前沿，正式结果保存论文使用的数值与图表，Git 保存演进历史。四者职责分开，使项目能够在长任务和上下文切换后继续推进。

## 阅读公开示例

建议使用 Python 3.11—3.13：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest shared/tests -q
```

最后一条命令检查共享工具、论文格式约定与仓库内链接。可继续阅读 [2026 B：无线电干扰源定位](../projects/2026-cumcm/solutions/problem-b-radio-interference/README.md) 和 [2026 C：微网调度](../projects/2026-cumcm/solutions/problem-c-microgrid/README.md) 的论文、图表与核心实现。

[AGENTS.md](../AGENTS.md) 汇总仓库入口与 authority，[AI 治理](../MCM_AI_Governance.md) 说明决策、自主执行、状态恢复和集成规则，[个人建模手册](../shared/templates/personal-modeling-playbook.md) 提供建模、实验、写作与交付方法。

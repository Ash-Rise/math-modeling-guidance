# 从决策到论文主张：联合遮蔽案例

本文是教学复盘，不是项目运行 authority，也不替代原题、Accepted Decisions、冻结结果或论文。它从 A 题中抽取一个真实决策，展示治理机制怎样改变实现、验证和表述。

## 1. 触发问题

多枚烟幕弹服务同一目标时，存在两种会改变正式时长的聚合口径：单个云团独立完成目标的完整遮蔽，或多个有效云团的空间并集共同遮蔽目标表面的全部视线。

两种口径会改变可行性判定、候选排序、正式目标值和附件中的解释，因此属于人类负责的模型语义。

## 2. Authority 消歧与 Decision Proposal

团队先回到原题、目标几何和结果模板。材料能够确定每枚烟幕弹的投放记录与服务对象，却不能唯一确定同一服务对象下多个云团的聚合判据，两种解释均有任务相关理由。

随后用一个固定方案做最小 pilot：找到一段正时长区间，其中任何单个云团都不能完整遮蔽，但云团并集可以覆盖全部视线。这个证据证明选择具有实质影响，于是形成 Decision Proposal，而不是让代码默认值替团队作答。

## 3. Accepted Decision

人类接受联合口径：对同一目标和同一时刻，以所有有效且指派给该目标的云团并集判断完整遮蔽；逐弹指派与正式总目标保持不变。旧的独立聚合条款被明确 supersede。

## 5. 最终主张与证据强度

论文可以主张“正式方案按联合完整遮蔽口径计时”，因为该主张由已接受语义、实现、反例测试、重新计算结果和机制图共同支撑。

论文仍只把有限搜索所得方案称为记录设置下的 best-found。联合判据解决了“怎样计时”，没有自动证明“搜索得到全局最优”。

## 6. 可复用模式

```text
实质歧义 → authority 消歧 → 最小 pilot → Decision Proposal
→ Accepted Decision / supersession → 实现与测试 → 正式结果 → 论文主张
```

如果 authority 已经唯一确定解释，或候选差异只来自实现方便，就不进入这条决策链。

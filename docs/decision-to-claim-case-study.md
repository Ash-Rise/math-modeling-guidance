# 从决策到论文主张：波动电价下的信息边界

本文从 2026 C 微网调度中抽取一个关键决策，展示 authority、模型决策、实现与论文主张之间的连接。

## 1. 触发问题

题目附件给出完整年度的实际电价序列，而调度策略按日和日内时点滚动执行。未来实际价格是否进入当时的采购决策，会直接改变购电时序、储能价值和年度费用，因此属于模型语义。

## 2. Authority 消歧与 Decision Proposal

团队回到题目中的实时波动场景和滚动决策顺序，将附件价格区分为两个角色：已发生价格形成历史信息，对应供电时段的实际价格负责执行与结算。

在实现前比较“未来实价进入规划”和“历史价格形成因果预测”两条路径，确认信息边界会实质改变优化结果，随后形成 Decision Proposal。

## 3. 关键决策

> 调度时仅以已发生价格形成未来价格预测；当前执行和最终结算采用对应供电时段的实际价格。

这一决定统一了价格预测、优化输入、实时执行和费用计算的时间边界。

## 4. 向下游传播

| 层级 | 具体体现 |
|---|---|
| 价格预测 | [`q4_prices.py`](../projects/2026-cumcm/solutions/problem-c-microgrid/src/q4_prices.py) 让每个预测器只接收当前时点以前的价格前缀 |
| 调度实现 | [`q4.py`](../projects/2026-cumcm/solutions/problem-c-microgrid/src/q4.py) 将预测价用于规划，将当期实价用于执行和费用结算 |
| 论文表达 | [微网调度论文](../projects/2026-cumcm/solutions/problem-c-microgrid/paper/paper.md) 在问题分析、模型建立与结果比较中沿用同一信息边界 |

源码中的边界断言进一步保证历史长度与决策时点一致，使这一决定成为可检查的实现合同。

## 5. 最终主张与证据强度

论文据此主张：未来价格未知时，以三周同点历史均值形成规划价格，并按对应时段实价执行和结算。该主张由模型决策、预测接口、调度实现和论文中的费用分解共同支撑。

年度费用比较反映当前价格预测与调度配置的整体效果；论文同时给出库存差异和适用边界，使结果强度与证据范围一致。

## 6. 可复用模式

```text
实质歧义 → authority 消歧 → 最小比较 → 模型决策
→ 实现合同 → 正式计算 → 论文主张与边界
```

这一模式适用于未来信息可见性、结算口径、风险参数含义等会改变正式结论的语义选择。

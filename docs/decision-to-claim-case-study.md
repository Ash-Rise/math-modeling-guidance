# 从决策到论文主张：联合遮蔽案例

本文从 A 题中抽取一个真实决策，展示 authority、Decision Proposal、实现、验证和论文主张之间的连接。

## 1. 触发问题

多枚烟幕弹服务同一目标时，存在两种会改变正式时长的聚合口径：单个云团独立完成目标的完整遮蔽，或多个有效云团的空间并集共同遮蔽目标表面的全部视线。

两种口径会改变可行性判定、候选排序、正式目标值和附件中的解释，因此属于人类负责的模型语义。

## 2. Authority 消歧与 Decision Proposal

团队先回到原题、目标几何和结果模板。材料确定了每枚烟幕弹的投放记录与服务对象，同时为同一服务对象下的两种云团聚合判据留下了选择空间，两种解释均有任务相关理由。

随后用一个固定方案做最小 pilot：找到一段正时长区间，其中单个云团各自覆盖部分视线，而云团并集可以覆盖全部视线。这个证据证明选择具有实质影响，团队据此形成 Decision Proposal 并明确选择聚合口径。

## 3. Accepted Decision

人类接受联合口径：对同一目标和同一时刻，以所有有效且指派给该目标的云团并集判断完整遮蔽；逐弹指派与正式总目标保持不变。旧的独立聚合条款被明确 supersede。

## 4. 向下游传播

| 层级 | 具体变化 |
|---|---|
| 实现 | [joint.py](../projects/2025-cumcm/solutions/problem-a-smoke-screen/src/smoke_screen/joint.py) 增加多云团联合覆盖判定 |
| 验证 | 测试覆盖“单云团均不充分、联合后充分”的反例，并继续检查时间与几何约束 |
| 结果 | 正式结果按新口径重新计算并进入当前结论 |
| 图表 | [联合机制图](../projects/2025-cumcm/solutions/problem-a-smoke-screen/figures/fig_joint_shielding_mechanism.png) 展示口径差异 |
| 论文 | 正文说明联合判据、适用范围和逐弹报告边界 |

## 5. 最终主张与证据强度

论文可以主张“正式方案按联合完整遮蔽口径计时”，因为该主张由已接受语义、实现、反例测试、重新计算结果和机制图共同支撑。

论文将有限搜索所得方案定位为记录设置下的 best-found。联合判据负责“怎样计时”，最优性表述由搜索范围和证据强度共同决定。

## 6. 可复用模式

```text
实质歧义 → authority 消歧 → 最小 pilot → Decision Proposal
→ Accepted Decision / supersession → 实现与测试 → 正式结果 → 论文主张
```

当 authority 已经确定解释时，项目直接进入实现；当多个实质解释继续成立时，使用这条决策链。
